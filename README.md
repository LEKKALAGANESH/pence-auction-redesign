# Pence Auction — Homepage Redesign

Four premium homepage design concepts for a fine-art & estate auction house — static HTML/CSS, no build step, built for client review.

## Preview

- `index.html` — hub page with tabs to switch between all 4 concepts (needs the other files alongside it — use this when hosting, e.g. GitHub Pages)
- `pence-all.html` — fully self-contained single file (logo + all 4 concepts inlined) — safe to send directly over email/WhatsApp

## Concepts

| # | File | Direction |
|---|------|-----------|
| 01 | `v1-heritage.html` | Heritage Editorial — navy & gold, classic auction-house gravitas |
| 02 | `v2-modern.html` | Modern Gallery — minimal white space, museum-style |
| 03 | `v3-warm-estate.html` | Warm Estate — terracotta & sage, inviting family-run feel |
| 04 | `v4-bold-tech.html` | Bold Auction-Tech — dark mode, live-bidding energy |

## Status

UI/UX concept review stage. Once a direction is locked, the remaining pages (Services, Auctions, Estate Sales, Contact) will be built on that system.
